# Security Policy

## Reporting Security Issues

The The Update Framework (TUF) maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/theupdateframework/python-tuf/security/advisories/new) form.

For more details, see the [The Update Framework (TUF) security policy](https://github.com/theupdateframework/python-tuf/blob/develop/SECURITY.md).
